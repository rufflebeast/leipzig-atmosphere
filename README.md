# Wetter über Leipzig · Weather above Leipzig

[Deutsch](#deutsch) · [English](#english)

## Deutsch

Live-Messdaten von drei Stationen in und bei Leipzig auf einer Webseite, auf Deutsch und Englisch:

- **Leipzig-Holzhausen** (Deutscher Wetterdienst): Bodenwetter
- **Institutsdach des TROPOS** in Leipzig: Wolkenradar, Lidar, Mikrowellenradiometer
- **TROPOS-Messfeld Melpitz**: Wolkenradar, Lidar, Mikrowellenradiometer, Regenmesser

Die Seite zeigt die letzten 48 Stunden: Temperatur, Niederschlag, Wasserdampf, Flüssigwasser in Wolken, Wolkenhöhen und einen Höhen-Zeit-Schnitt der Cloudnet-Klassifikation (Tröpfchen, Eis, Regen, Aerosol, Insekten).

### Aufbau

```
app/          Webseite (HTML, CSS, JavaScript ohne Build-Schritt)
  i18n.js     Texte, die JavaScript erzeugt, in beiden Sprachen
  app.js      Laden der Daten, aktuelle Werte, Warnung bei veralteten Daten
  charts.js   Diagramme mit uPlot, Klassifikation als eigene Zeichenfläche
pipeline/     Python: Daten holen und als kompakte JSON-Dateien ablegen
  dwd_holen.py        DWD-Werte von Bright Sky → app/data/dwd.json
  cloudnet_holen.py   Cloudnet-Dateien (NetCDF) → app/data/cloudnet.json
  test_pipeline.py    Tests der Rechenschritte
.github/      GitHub Actions: Tests, Pipeline alle 20 Minuten, Veröffentlichung
```

Der Browser lädt nur Dateien von diesem Server. Die Pipeline holt die Daten bei DWD (über Bright Sky) und Cloudnet, fasst sie zusammen, sortiert fehlerhafte Messungen aus und schreibt sie als JSON in `app/data/`. Cloudnet-Dateien lädt sie nur neu, wenn sich ihre Prüfsumme geändert hat.

### Lokal ausführen

```
python3 -m venv ~/venvs/wetterdemo
~/venvs/wetterdemo/bin/pip install -r pipeline/requirements.txt
~/venvs/wetterdemo/bin/python -m unittest discover -s pipeline
~/venvs/wetterdemo/bin/python pipeline/dwd_holen.py
~/venvs/wetterdemo/bin/python pipeline/cloudnet_holen.py
python3 -m http.server 5185 --directory app
```

Dann im Browser `http://localhost:5185` öffnen, für Englisch `http://localhost:5185/?lang=en`.

## English

Live measurements from three stations in and near Leipzig, Germany, on one web page in German and English:

- **Leipzig-Holzhausen** (German Meteorological Service, DWD): surface weather
- **Roof of the TROPOS institute** in Leipzig: cloud radar, lidar, microwave radiometer
- **TROPOS field site Melpitz**: cloud radar, lidar, microwave radiometer, rain gauge

The page shows the last 48 hours: temperature, precipitation, water vapour, cloud liquid water, cloud heights and a time-height section of the Cloudnet classification (droplets, ice, rain, aerosol, insects).

### Structure

```
app/          Web page (HTML, CSS, JavaScript without a build step)
  i18n.js     Texts generated by JavaScript, in both languages
  app.js      Data loading, current values, warning for outdated data
  charts.js   Charts with uPlot, classification drawn on its own canvas
pipeline/     Python: fetch data and store it as compact JSON files
  dwd_holen.py        DWD values from Bright Sky → app/data/dwd.json
  cloudnet_holen.py   Cloudnet files (NetCDF) → app/data/cloudnet.json
  test_pipeline.py    Tests of the processing steps
.github/      GitHub Actions: tests, pipeline every 20 minutes, publishing
```

The browser only loads files from this server. The pipeline fetches the data from the DWD (via Bright Sky) and Cloudnet, aggregates it, removes faulty measurements and writes JSON to `app/data/`. Cloudnet files are only downloaded again when their checksum has changed.

Code comments and identifiers are in German.

### Running locally

See the commands in the German section above. Open `http://localhost:5185/?lang=en` for English.
